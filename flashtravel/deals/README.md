# Deal briefs

Drop a markdown file here, one per deal. Phase 2 wires the agent to watch this folder (or the "+ New deal" dashboard form) and kick off generation.

Format is loose on purpose. The agent reads the whole file. Still, include:

- A `# Title` line.
- `supplier`, `category` (one of: `cruise`, `all-inclusive`, `disney`, `sandals-beaches`), `dates`, `price`, and `origin` as `key: value` lines near the top.
- Prose below describing what's included, what's not, what makes the deal interesting, and any legal fineprint.

See `sample.md` for a working example.
